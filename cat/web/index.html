Core Capabilities

Oracle Database Backend

Enterprise-grade project & annotation storage with multi-user support

Shapefile Overlay Support

Import bathymetry, transects, zones, and reference layers

Cloud-Optimized Geospatial (COG)

Stream high-resolution orthomosaics from cloud storage

Precision Annotation

Sub-centimeter accuracy with high-zoom detail for taxonomy

Vector Geometry Tools

Polygons, polylines & point markers with editable vertices

Standards-Based Export

GeoJSON, Shapefile, CSV with WGS84 projection support
