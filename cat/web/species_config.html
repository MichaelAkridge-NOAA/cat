Other Fields

Options unchecked here are hidden from the annotation form immediately, on every project. An annotation that already has a since-disabled value keeps showing it (labeled "retired") wherever that annotation is viewed or edited — nothing existing is ever hidden or changed. Deployment-wide setting.

Default Values

A starting value for a NEW annotation's field, deployment-wide. Only applies when the analyst hasn't set their own "Set Defaults" for this session and has no personal preference saved for it — see Preferences → Default annotation settings for the account-level tier, which always wins over this one.
